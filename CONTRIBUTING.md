# Contributing

Bug reports go through the issue form, it asks for your GPU, driver, version and the server log, that's usually all we
need.

Pull requests are welcome. Keep them to one change and say what you tested it on (GPU, driver, what you ran). Anything
that touches the kernels, the KV cache, the drafter or xyz-engine has to give the exact same text as before, so include
a before and after on the same prompt with the same seed.

Questions, your own numbers and ideas go in Discussions.
